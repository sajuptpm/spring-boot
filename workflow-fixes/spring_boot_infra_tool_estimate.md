## 2. Key Observations & Category Groupings

1. **Category `Build` (`ci.yml`, `build-pull-request.yml`) — MANDATORY**:
   - Requires compute runners (4-core `$0.012/min`) to compile 448 monorepo modules without OOM.
   - Upstream uses Develocity (`ge.spring.io`) for remote build caching and Google Chat webhooks for alerting.
2. **Category `Package` (`build-and-deploy-snapshot.yml`) — MANDATORY**:
   - Publishes snapshot JARs, POMs, and Gradle metadata. Upstream relies on JFrog Artifactory (`$1,800/yr`) and dispatches documentation builds (`$252/yr`).
3. **Category `Test` (`run-system-tests.yml`, `verify.yml`)**:
   - `run-system-tests.yml` is **Mandatory** because it verifies Spring Boot with Testcontainers against real containerized services. Upstream requires Docker Hub Team (`$180/yr`) to avoid rate limits.
   - `verify.yml` is **Not Mandatory** for open-source forks because it tests proprietary JEE application servers (WebLogic/WebSphere) via a closed Broadcom repository.
4. **Category `Release` (`publicize-release.yml`, `publicize-milestone.yml`)**:
   - `publicize-release.yml` is **Mandatory** to publish final GA release notes and the Gradle plugin. Upstream requires code-signing certificates (`$996/yr` DigiCert KeyLocker).
   - `publicize-milestone.yml` is **Not Mandatory** because milestone releases are optional interim checkpoints.
5. **Category `Internal to Vendor` (`release-train-*.yml`) — NOT MANDATORY**:
   - All 6 release train workflows are proprietary Broadcom cross-portfolio synchronization tools. Independent forks do not participate in Broadcom's internal release train.
6. **Category `Utility` (`run-codeql-analysis.yml`) — MANDATORY**:
   - Provides automated Static Application Security Testing (SAST) to maintain security hygiene. Free for public repositories.
